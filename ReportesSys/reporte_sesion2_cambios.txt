1. ai_rag_service/domain/ports/knowledge_repository_port.py
────────────────────────────────────────────────────────────────────────────────

Tipo: Interfaz abstracta (ABC) · Puerto hexagonal
Propósito: Definir el contrato para la "Capa Cero" de tolerancias de pH

Código completo:

    from abc import ABC, abstractmethod
    from typing import Optional

    class KnowledgeRepositoryPort(ABC):
        """Port that the ExplainPhUseCase depends on for Capa Cero caching."""

        @abstractmethod
        async def get_ph_tolerance(self, species: str) -> Optional[dict]:
            """Return {"min": float, "max": float, "optimal": float} or None."""
            ...

        @abstractmethod
        async def save_ph_tolerance(self, species: str, data: dict) -> None:
            """Upsert tolerance row.  Must be idempotent (no duplicates)."""
            ...

Justificación:
  · El ExplainPhUseCase recibía knowledge_repo=None porque no existía la interfaz
  · Ahora depende de esta ABC, cumpliendo la Dependency Inversion Principle
  · En producción la implementa SupabaseKnowledgeRepo; en tests, un dict en memoria

2. ai_rag_service/infrastructure/database/supabase_knowledge_repo.py
────────────────────────────────────────────────────────────────────────────────

Tipo: Adaptador concreto · Infraestructura
Propósito: Comunicarse con Supabase vía PostgREST para leer/escribir tolerancias

Código completo:

    import logging
    from typing import Optional
    import httpx
    from domain.ports.knowledge_repository_port import KnowledgeRepositoryPort

    logger = logging.getLogger(__name__)

    class SupabaseKnowledgeRepo(KnowledgeRepositoryPort):
        """Reads/writes pH tolerance rows via Supabase PostgREST."""

        def __init__(self, supabase_url: str, supabase_key: str,
                     http_client: httpx.AsyncClient):
            self._base = supabase_url.rstrip("/")
            self._headers = {
                "apikey": supabase_key,
                "Authorization": f"Bearer {supabase_key}",
                "Content-Type": "application/json",
                "Prefer": "return=representation",
            }
            self._http = http_client

        async def get_ph_tolerance(self, species: str) -> Optional[dict]:
            url = (
                f"{self._base}/rest/v1/plant_knowledge"
                f"?species=eq.{httpx.QueryParams({'': species}).get('')}"
                f"&select=ph_min,ph_max,ph_optimal"
                f"&limit=1"
            )
            try:
                resp = await self._http.get(url, headers=self._headers, timeout=5.0)
                resp.raise_for_status()
                rows = resp.json()
                if not rows:
                    return None
                row = rows[0]
                return {
                    "min": float(row["ph_min"]),
                    "max": float(row["ph_max"]),
                    "optimal": float(row["ph_optimal"]),
                }
            except httpx.HTTPStatusError as exc:
                logger.warning("Supabase GET failed (%s): %s",
                               exc.response.status_code, exc)
                return None

        async def save_ph_tolerance(self, species: str, data: dict) -> None:
            url = f"{self._base}/rest/v1/plant_knowledge"
            headers = {
                **self._headers,
                "Prefer": "resolution=merge-duplicates,return=representation",
            }
            payload = {
                "species": species,
                "ph_min": data["min"],
                "ph_max": data["max"],
                "ph_optimal": data.get("optimal", (data["min"] + data["max"]) / 2),
            }
            try:
                resp = await self._http.post(url, json=payload,
                                              headers=headers, timeout=5.0)
                resp.raise_for_status()
                logger.info("Persisted pH tolerance for '%s' to Supabase.", species)
            except httpx.HTTPStatusError as exc:
                logger.error("Supabase UPSERT failed (%s): %s",
                             exc.response.status_code, exc)
                raise

Decisiones de diseño:
  · SIN supabase-py SDK → se usa httpx directamente contra PostgREST
  · Cero dependencias nuevas (httpx ya está en requirements.txt)
  · UPSERT idempotente vía header "Prefer: resolution=merge-duplicates"
    que aprovecha la restricción UNIQUE en la columna species
  · Timeout de 5 segundos en ambas operaciones
  · Errores logueados con nivel WARNING (GET) y ERROR (POST)

Tabla Supabase requerida (DDL):

    CREATE TABLE IF NOT EXISTS plant_knowledge (
        id          BIGSERIAL PRIMARY KEY,
        species     TEXT UNIQUE NOT NULL,
        ph_min      REAL NOT NULL,
        ph_max      REAL NOT NULL,
        ph_optimal  REAL NOT NULL,
        updated_at  TIMESTAMPTZ DEFAULT now()
    );

4. ai_rag_service/application/use_cases/explain_ph_use_case.py
   → Reescritura completa de _get_sensor_alerts()
────────────────────────────────────────────────────────────────────────────────

ANTES (inservible — llamaba método inexistente):

    def _get_sensor_alerts(self, sensors: dict) -> list[str]:
        alerts = []
        if self.sensor_validator:
            alerts = self.sensor_validator.validate_batch(sensors)
        ...

DESPUÉS (construye SensorData, llama validate(), captura ValidationError):

    def _get_sensor_alerts(self, sensors: dict) -> list[str]:
        alerts: list[str] = []
        if self.sensor_validator is not None:
            try:
                from domain.models import SensorData
                data = SensorData(
                    temperature=sensors.get("temperature"),
                    humidity=sensors.get("humidity"),
                    uv_index=sensors.get("uv_index"),
                    soil_humidity=sensors.get("soil_humidity"),
                    ph_level=sensors.get("ph_level"),
                )
                self.sensor_validator.validate(data)
                # Si no lanza excepción → valores válidos → sin alertas
                return alerts
            except Exception as exc:
                # ValidationError → el mensaje ES la alerta
                alerts.append(str(exc))
                return alerts

        # Fallback — reglas básicas cuando no hay validator inyectado
        temp = sensors.get("temperature")
        humidity = sensors.get("humidity")
        if temp is not None and temp > 35:
            alerts.append(f"ESTRÉS TÉRMICO SEVERO — temperatura {temp}°C supera 35°C.")
        if humidity is not None and humidity < 20:
            alerts.append(f"DESHIDRATACIÓN CRÍTICA — humedad {humidity}% debajo de 20%.")
        return alerts

Razón del cambio:
  · SensorValidator NO tiene método validate_batch() — solo validate(SensorData)
  · Se construye un SensorData desde el dict de sensores del payload REST
  · SensorValidator.validate() lanza ValidationError si un valor es físicamente
    imposible (e.g. temperatura=999 fuera del rango [-50, 60])
  · El fallback de reglas básicas se mantiene para retrocompatibilidad
    cuando sensor_validator=None (e.g. en tests sin DI completa)
