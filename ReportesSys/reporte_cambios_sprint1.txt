Archivo modificado: apps/core/presentation/serializers.py

Clases añadidas (en orden de composición):

    Uso: payload completo que envía el Edge Node por cada ciclo de telemetría

  SensorBatchSerializer
    Campos:
      - batch (ListField de SensorReadingSerializer, [1–500 elementos])
    Uso: wrapper para el endpoint /batch/ que acepta hasta 500 lecturas por POST

SECCIÓN E — MOTOR DE EXPLICABILIDAD (Bloque 2 del sprint)
────────────────────────────────────────────────────────────────────────────────

Archivo creado: ai_rag_service/application/use_cases/explain_ph_use_case.py

  PH_TOLERANCE_DB (dict hardcodeado):
    Tabla de tolerancias para 7 especies agrícolas comunes + clave "default".
    Actúa como último fallback (Capa Blanca simbólica):
      Zea mays, Solanum lycopersicum, Phaseolus vulgaris, Capsicum annuum,
      Cucurbita pepo, Solanum tuberosum, Mangifera indica, default

  PhExplanationResult (dataclass):
    Contiene: ph_raw, ph_status, deviation, reasoning, recommendations,
    sensor_context, species_used, confidence, data_sources

  ExplainPhUseCase.execute(ph_cnn, plant_id, sensors, species_name):
    Flujo:
      1. _get_tolerance() → Supabase (Capa Cero) → BotanicalFallbackGateway →
         tabla hardcodeada → default
      2. _classify_ph()  → "optimal" | "warning" | "critical"
      3. _build_reasoning() → texto legible para el agricultor (Caja Blanca)
      4. _get_sensor_alerts() → delega a SensorValidator o aplica reglas básicas
      5. _build_recommendations() → acciones concretas según status + alertas
      6. Retorna PhExplanationResult completamente auditable

Archivo modificado: ai_rag_service/application/use_cases/__init__.py
  + ExplainPhUseCase exportado en __all__

SECCIÓN F — BOTANICAL GATEWAY (Bloque 3 del sprint)
────────────────────────────────────────────────────────────────────────────────

Archivo creado: ai_rag_service/infrastructure/external/botanical_gateway.py

  TrefleAdapter:
    - GET https://trefle.io/api/v1/plants/search?q={species}&token={token}
    - Timeout: 5 segundos
    - Extrae: growth.ph_minimum / growth.ph_maximum
    - Devuelve None si la respuesta no contiene datos de pH

  FarmVillageAdapter:
    - GET https://api.farmvillage.io/v1/crops/ph?crop={species}
    - Timeout: 5 segundos
    - Extrae: ph_min / ph_max / ph_optimal
    - Devuelve None si la respuesta falla o no contiene datos

  BotanicalFallbackGateway.fetch_tolerance(species_name):
    - asyncio.gather(trefle.fetch(), farmvillage.fetch(), return_exceptions=True)
    - Trefle tiene prioridad; FarmVillage es respaldo secundario
    - Devuelve None si ambas APIs fallan (sin lanzar excepción)
    - Patrón: Race + Fallback paralelo; latencia = max(T_trefle, T_farmvillage)

SECCIÓN H — EDGE NODE (Bloque 4 del sprint)
────────────────────────────────────────────────────────────────────────────────

Archivos creados en el directorio edge_node/:

  edge_node/__init__.py
    Marca el directorio como paquete Python. Contiene nota de arquitectura.

  edge_node/store_forward_daemon.py
    - init_db(): crea tabla pending_readings + índice UNIQUE (device_id, timestamp)
    - enqueue_reading(): INSERT OR IGNORE (idempotente)
    - sync_to_backend(): fetch hasta 200 filas no sincronizadas → POST batch
      → marca synced=1 solo si el backend responde HTTP 2xx
    - main(): bucle async cada SYNC_INTERVAL_SECONDS (default 30)
    - Configuración via .env: EDGE_DB_PATH, BACKEND_BATCH_URL, HARDWARE_API_KEY,
      SYNC_INTERVAL

  edge_node/mqtt_local_subscriber.py
    - Usa paho.mqtt.client.CallbackAPIVersion.VERSION2 (API moderna)
    - Topic: mole/sensors/#
    - on_message(): parsea JSON del ESP32 → llama enqueue_reading()
    - Conecta al broker MQTT local (LAN, sin salir a internet)

  edge_node/inference.py
    - Carga modelo TFLite desde variable de entorno TFLITE_MODEL_PATH
    - preprocess_image(): carga imagen con Pillow → convertir RGB→HSV→tensor
    - run_inference(): ejecuta el intérprete TFLite → devuelve float [0.0, 14.0]
    - Mock mode: si tflite_runtime no está instalado, devuelve random.uniform(5.5, 7.5)
    - enqueue_cnn_result(): crea conexión SQLite temporal → enqueue_reading()
    - CLI via argparse: python inference.py --image foto.jpg [--device-id X] [--plant-id Y]

  edge_node/requirements.txt
    httpx>=0.26, paho-mqtt>=2.0, python-dotenv>=1.0,
    tflite-runtime>=2.14, Pillow>=10.0, numpy>=1.24
